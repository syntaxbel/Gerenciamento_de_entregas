# 📦 Controle de Entregas - Portal de Logística

O **Controle de Entregas** é um sistema web moderno e responsivo projetado para o gerenciamento e rastreamento de entregas de forma eficiente. O projeto conta com um painel administrativo (dashboard) interativo, tabelas de monitoramento de status e uma área de autenticação segura para controle de acesso dos administradores.

---

## 🚀 Funcionalidades

- **Sistema de Autenticação:** Tela de login integrada com backend em PHP para validação de usuários administrativos e segurança de sessão.
- **Dashboard Interativo:** Painel visual com métricas e indicadores de desempenho de logística.
- **Acompanhamento em Tempo Real:** Tabelas estruturadas para exibição e monitoramento do progresso das entregas.
- **Badges de Status Dinâmicos:** Identificação visual rápida para o estado de cada entrega (Ex: *Pendente*, *Em Trânsito*, *Entregue*).
- **Níveis de Acesso:** Controle e diferenciação de permissões para perfis administrativos.
- **Design Responsivo:** Interface adaptável para diferentes tamanhos de tela (Desktops, Tablets e Smartphones) usando CSS moderno.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído dividindo as responsabilidades entre uma interface rica no front-end e um controle de acesso direto no back-end:

### Front-End
- **HTML5:** Estruturação semântica da plataforma, tabelas de dados e formulários.
- **CSS3:** Estilização personalizada, layouts modernos (Flexbox/Grid), responsividade e componentes visuais como os badges de status.
- **JavaScript (ES6):** Manipulação dinâmica do DOM, interatividade do dashboard e comportamento dos componentes da página.

### Back-End
- **PHP:** Lógica de autenticação da tela de login, validação de credenciais.
